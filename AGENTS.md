# Project Rules (`momentum_flow`)

## GitHub Deployment Rule
- **Always Push Changes to GitHub**: Whenever any code, configuration, or documentation changes are made in this repository, you MUST stage, commit, and push them to GitHub (`git push origin main`) before concluding your task so the user can immediately view and test the live updates (`https://talsheaffer.github.io/momentum_flow/`).
- Verify `git status` is clean and the push to `origin` succeeded after every change.
